# 火纹改版工具（fe_editor）

安卓端 GBA《火焰之纹章》三部曲 ROM 改版工具。Flutter 实现，零第三方插件依赖。

**接手开发前请先读 `~/workspace/AGENTS.md`**——里面有构建命令、字段布局、已知的坑和待办。

> **版本与状态**（当前 `2.3.20`）：
> - **文本写入（阶段三，v2.3.20）**：文本查看器点开任一条目即可编辑保存。支持**明文 UTF-8 / 明文 GBK /
>   Huffman（SJIS 与中文码表）**；等长原地覆盖 → 变短提前结束符 → 变长找最长 0xFF 空位重指指针，
>   Huffman 则重定位写入（用 ROM 自带树逆编码）。含控制码的对话用〔XX〕占位符保留控制码。
> - **道具详情页可勾选特性（IA_* 标志位）**（v2.3.17）：把某把武器的特性复制给别的武器——
>   无限耐久 / 连击两次 / 逆转武器三角 / 无视防御等 9 项，按位写、可撤销；
>   其中「无限耐久」可**逐件**改（同修改器批量预设同一机制，但只动本道具）。
>   详情页那组职业列表按真实含义改名为**克制职业**（该武器对其有额外伤害，非装备限制）。
> - **入口**：游戏数据 = 角色 / 职业 / 道具 / 章节；素材预览 = 肖像 / 文本 / 战斗动画；
>   工具 = 修改器 / 十六进制 / 反汇编 / 空位搜索 / 表地址 / 设置 / 日志 / 关于。
> - **「章节」页**（v2.3.03 起）：原来的「关卡地图」与「章节单位」已合并成一页，
>   上半屏是地图、下半屏是本章单位，地图上直接显示真实的地图小人。
> - **反汇编**（v2.3.10 起，v2.3.11 增强）：工具区「反汇编」按地址列出
>   「地址 / 机器码 / 汇编」，可切 ARM / Thumb、按地址跳转、按汇编文本搜索，
>   点分支指令直接跳目标。v2.3.11 起**可直接改机器码**（可撤销）、
>   **自动识别指令集**、从十六进制页/章节事件一键跳进来、**追踪函数调用链**。
> - **章节事件**（v2.3.09 起，v2.3.14 补齐三作）：单位列表上方新增「事件 N 个 · 剧情增援 M 人」入口，
>   点开可看本章的触发条件（第 N 回合起 / 角色阵亡 / 访问 (x,y)）与剧情增援
>   （角色 / 职业 / 坐标 / 阵营 / 等级 / 装备，会跟 `CALL` 子脚本与事件槽）。只读，不支持改事件脚本。
> - **章节敌方配置**（v2.3.05 起）：FE8 有遭遇战的 12 章可在「遭遇敌方 1-3」槽直接改敌军；
>   FE6 开红/蓝两路静态单位（敌军即红方）。剧情中途生成的增援既在「章节事件」面板里、
>   也直接列进了单位列表（标「事件」，只读）。
> - **暗色模式**（v2.3.01 起）：设置页 → 外观，可选 跟随系统 / 浅色 / 暗色。
> - **补丁库已移除**（不再内置社区补丁）；UPS/IPS 补丁格式的导出与导入仍保留。
> - **游戏内调试器入口已移除**（v2.3.03 起）：补丁装完会导致游戏无法启动，
>   修好前不对外提供。详见文末「已知限制」。
> - **修改器预设实机化**（v2.3.08）：删掉「满级」与「全职业移动力 9」（会连敌方一起变强）；
>   能力上限改为 50 / 生命 60（受原版存档机制限制）。新增「敌方嫌疑名单」拦截——
>   手动选了图鉴 / 全表口径时，确认弹窗会点名那些大概率是敌方的角色。
> - **道具小图标**（v2.3.13）：道具列表每行显示游戏里的 16×16 图标（名称左边），
>   详情页顶部放大显示。五个版本都支持，改版沿用同一指针槽也能显示。
> - **自定义角色名单**（v2.3.12）：作用范围里可选「自定义名单（手工勾选）」，
>   以当前判据结果为初始勾选，可补勾/取消；支持一键复制成 `1,2,5,12` 分享，
>   也能从剪贴板导入（不弹键盘，自动从任意文本抽数字）。
> - **新作用范围「按章节出场」**（v2.3.09）：改版常不给主线主角配支援对话，'
>   「支援互惠」判据会漏掉他，成长率类预设就「看起来没用」。新判据把章节初始单位里
>   出场过的角色也算进来（自动排除对战/试炼塔章节）。
>   职业 / 肖像 / 道具 列表页加搜索，支援对象与可用职业可点击跳转。
> - 安装包同时支持 32 位（armeabi-v7a）与 64 位（arm64-v8a）设备。

## 功能

- **ROM 识别**：不依赖 game code，改用「结构匹配」——看哪个版本的指针槽在 ROM 里全部有效。能兼容改版改写 game code、以及打补丁把寻址扩展到 16MB 以外的情况（如 20MB 重度改版「铠甲的呼唤」，其角色名/职业名可正常显示）
- **角色（整合页）**：一个角色一处看全——页头是**肖像 + 职业**（点肖像进肖像详情、点职业进职业编辑），
  下面是基础数值/成长率与 8 项武器熟练度，均可编辑。列表带缩略图与职业名，支持按名字搜索。
  属性与体格按**有符号字节**解析（0xFF 显示为 -1，而非 255）。改动可撤销，导出前不写文件。
  另有「属性 / 支援」区：显示角色属性（炎/雷/风/冰/闇/光/理）；支援关系每条都可改
  对象角色 ID / 初始支援值 / 每回合增长
  列表 ID 恒等于表内偏移，空条目显示为「（未命名）」而不跳过
- **职业表**：移动力、体格、基础值、**能力上限**、成长率、**转职加成**、8 项武器熟练度
  （与角色页共用同一套字段组件）。改「能力上限」才能让角色突破职业自带的属性天花板。
  列表每行带该职业的**地图小人**缩略图（地图上跑的那个 sprite），取不到时回退地图头像；
  详情页顶部可看**地图小人 / 地图头像（32×32）/ 职业卡（80×80）**
- **道具浏览**：按种类分组（剑 / 枪 / 斧 / 弓 / 杖 / 理光闇魔法 / 消耗品 / 指环 / 龙石），可搜索、可按种类筛选。
  列表每行名称左边显示**游戏里的 16×16 小图标**（v2.3.13 起），详情页顶部再放大一份。详情页显示：
  - 种类、可装备、特性（u32 attributes：连击两次 / 无限耐久 / 逆转武器三角 / 无视防御等；
    v2.3.17 起下方有「特性（IA_* 标志位）」勾选区，可把某武器的特性复制给别的武器）
  - 使用次数 / 耐久（游戏里「46/46」的分母）
  - 威力、命中、重量、必杀、射程
  - 单价（**u16**）与商店售价（= 耐久 × 单价）
  - 武器等级（E~S）与熟练度累计值（FE6 与 FE7/FE8 各一套档位）
  - 武器特效（毒 / 吸血 / 减半 / 魔剑，FE8 多石化）/ 使用效果 / 武器经验
    （`bmitem.h` 尾段三字段，v2.3.06 起只读展示；FE6 条目 32 字节，武器经验强制 0）
  - 数值加成（HP/攻击/技巧/速度/防御/魔防/幸运/移动/体力）
  - 克制职业列表（该武器对这些职业有额外伤害；并非限制谁能装备，v2.3.17 起文案已更正）

  「可编辑字段」区可改：使用次数 / 威力 / 命中 / 重量 / 必杀 / 射程 / 单价 / 武器等级 / 图标 ID。
  「特性（IA_* 标志位）」区可勾选：无限耐久 / 不可出售 / 连击两次 / 魔法伤害 / 无法反击 /
  逆转武器三角 / 无视飞行特效 / 必杀无效 / 无视防御（按位写，不影响其它位，可撤销；
  不开放 bit0/1/2 类型位——改了等于把剑变成杖）。
  单价按 **u16** 写（改 50000 不会被截成 80）；射程是下拉选的合法组合
  （写个非法码进去，游戏里这个道具就没有射程了）
- **肖像浏览**：枚举全部角色肖像，按 sheet 拼装 96×80 正脸，另可看半目/闭眼、嘴型帧、32×32 地图头像与 80×80 职业卡（只读，自动适配 FE6/FE7/FE8 三种数据布局与 LZ77）
- **文本查看器**：枚举全部对话文本，控制码渲染为可读符号，支持搜索；自动适配五种文本引擎
  （标准 Huffman+SJIS / 明文 GBK 汉化 / 明文 UTF-8 改版 / Huffman+中文码表汉化 / 未识别）。
  **v2.3.18 起可写，v2.3.20 支持 Huffman 与控制码对话**（阶段三）：点开条目即可编辑保存。
  支持**明文 UTF-8 / 明文 GBK / Huffman（SJIS 与中文码表）**——等长原地覆盖，变短提前放结束符，
  变长选最长 0xFF 空闲块写入并重指指针表，Huffman 则用 ROM 自带树逆编码后重定位。
  含控制码的对话用〔XX〕占位符保留控制码；改动可整体撤销、导出前不落盘。
  角色/职业/道具详情页笔形按钮可直接改名（v2.3.19）。只剩**未识别引擎**不可写。
  注意：汉化版显示的是游戏内原文（同音字），不换正式译名——查文本要看真实内容。
- **战斗动画**：枚举全部战斗动画（FE6 122 / FE7 162 / FE8 201 条），按 12 种模式
  逐帧浏览并可播放，可切换自军/敌军/友军/灰色四套配色，导出当前帧与图形 sheet 为 PNG。
  只读浏览，暂不支持导入。
- **章节**：地图与初始单位合在一页，一个章节一屏看完。
  - 上半屏是地形图：按屏幕宽度自适应缩放，可手动放大缩小；
    点任意格子会在下方显示 `(x, y)`、地形名与站在该格的单位。
  - 地图上直接叠加**真实的地图小人**（与游戏内一致），我方为蓝、敌方为红、友军为绿；
    带两套 chipset 的章节（如烈火之剑第 5 章）已能正确拼接，不再出现白点。
  - 下半屏是本章单位列表：可改坐标 / 等级 / 职业 / 道具，改动可整体撤销。
    **v2.3.15 起事件脚本生成的单位也并到这个列表**（行尾标「事件」与阵营，只读），
    同一角色同坐标不会重复列；圣魔的遭遇战 6 槽不混入（那是遭遇战配置）。
  - 单位入口按版本区分：我方（普通 / 困难）（FE7/FE8）；
    **遭遇我方 1-3 / 遭遇敌方 1-3（仅 FE8）**——原版有遭遇战的 12 章（第 4/7/11/13/17/18/24/26/30/31 等）
    敌军就配在遭遇敌方槽里，可直接改；
    **红方（敌军）/ 蓝方（我军）（仅 FE6）**——FE6 红/蓝两路静态单位全部可读可改。
  - 剧情中途生成的增援：v2.3.09 起可在「章节事件」面板里看到（递归跟 `CALL` 子脚本，
    按版本用正确的 20/16 字节 `UnitDefinition` 解析）；静态表里没有，列表旁会注明。
    **v2.3.14 起封印之剑 / 烈火之剑也能读**（之前只有圣魔能读），
    人数按单位去重（同一组增援常被多个回合事件引用），坐标落在地图外的会标「图外」。
    **v2.3.15 起这些单位直接并进下方单位列表**（标「事件」，只读）。
  - **章节事件面板**（v2.3.09）：单位列表上方的「事件 N 个 · 剧情增援 M 人」入口，
    点开看本章的触发条件与增援名单。触发条件只识到回合/角色/地点/其他四大类
    （`EventInfo` 的 12/16 字节条目，封印与圣魔 12 字节、烈火 16 字节），
    位置/角色类按位域解出座标与 pid；其余子命令保留原始值供对照。只读。
  - FE6 也已支持（v2.3.05，走 `chapterinfo.h` 的红/蓝两路，不需要解析事件脚本）。
  - **陷阱叠加层**（v2.3.06）：地图工具栏可开关琥珀色菱形标记，
    数据来自事件组 `traps`/`extraTrapsInHard` 槽（`bmtrap.h` 的 6 字节 `TrapData`，
    类型名取反编译 `TRAP_*` 枚举：弹弓/火地板/毒气/地雷/哥尔工蛋…）；
    工具栏显示陷阱数量。FE8 全章已验证（原版 8 章有数据，如第 19/32 章的哥尔工蛋），
    改版（铠甲的呼唤）同槽位数据仍在；FE7 有陷阱数据但 8 字节记录结构未验证，
    只显示数量不画标记；FE6 没有陷阱槽。
- **反汇编查看器**：工具区「反汇编」。GBA 是 ARM7TDMI，代码里 ARM 与 Thumb 两套
  指令集混用，页面顶部可切换（默认 Thumb，游戏大多数函数是 Thumb 形式）。
  - 每行显示「GBA 地址 / 机器码 / 汇编」，如 `08001000  0449  ldr r1, [pc, #16]`
  - **点击带分支目标的指令**（`b` / `bl` / 条件跳转）直接跳到目标地址；长按任意行复制该行
  - **字面池取数标注真实地址与取值**：`ldr r1, [pc, #16] @ =0x08001014 (0x0300000C)`
  - **跳转**：接受 `08000000`（GBA 地址）与文件偏移两种写法；首尾有「上一屏 / 下一屏」
  - **搜索**：按汇编文本搜（`ldr r0` / `bl` / `push`），显示命中数并支持「下一个」
  - 解码器用 GNU `objdump` 逐条校准：Thumb 3810 条完全一致；ARM 6000 条里
    除 ARMv5 扩展指令（`movw`/`movt`/`smmls` 等，GBA 用不到）外一致
  - **改机器码**（v2.3.11）：点任意一行选中，底部出现数字键盘；点某个字节后
    输入两位十六进制即写回，改完的字节高亮。右上角撤销可整体还原，
    改动同样会体现在导出的 GBA/UPS 补丁里
  - **自动识别指令集**（v2.3.11）：跳转与点分支时按目标处内容自动切 ARM/Thumb
    （按指令密度与函数序言特征打分），顶部图标可关掉改成手动
  - **上下文入口**（v2.3.11）：十六进制页右上角「从当前位置反汇编」；
    章节事件面板每条事件都有「反汇编打开」，能直接看事件脚本的命令流
  - **函数追踪**（v2.3.11）：右上角「追踪当前函数」列出该函数调用了哪些子函数
    （可点击跳转）与字面池引用的数据
- **十六进制编辑器**：按地址查看与修改任意字节、按十六进制搜索。
  每行字节数按屏幕宽度自适应；**点选字节后用底部 0-F 数字键盘改值**（不再弹框），
  输入满两位自动写回；底部状态栏显示 值 / 文件偏移 / GBA 地址 / ROM 大小。
  改过的字节有底色标记。
- **空位搜索**：查找连续 FF/00 空白区
- **游戏内调试器**：**入口已移除（v2.3.03 起）**。代码与补丁数据仍在仓库里
  （`lib/core/game_debugger.dart`、`assets/debugger/`），但 `Features.gameDebugger`
  设为 `false`，界面不再显示入口。
  原计划是把社区著名的 **Nergal 调试器**（Vesly 的 `TiaMfLNiAyotDI`）做成一键安装，
  装进 ROM 后在战斗地图按 **B** 呼出菜单。
  **实测日版与汉化版装完后均无法启动（白屏 / 黑屏）。**
  已定位到三处确定性缺陷（详见 `AGENTS.md` 第 20c 节）：
  跳板目标与 payload 写在同一个地址区间会互相覆盖；`0xCC66C` 的跳板目标丢了
  `0x08` 前缀；上游 `PUSH` 数据体被当 hook 写进 ROM 覆盖了原版函数入口。
  这三条**尚未在模拟器/实机上逐条验证**（开发容器内没有 GBA 模拟器），
  所以修好前不对外开放。`GameDebuggerPatch.validate()` 已能静态检出前两类问题。
- **修改器**：12 个批量预设——成长率拉满 / 成长率 200% / 属性强化 /
  熟练度 S / 三倍经验 / **职业能力上限 50（生命 60）**（v2.3.08 下调，
  受原版存档机制限制；与「成长率 200%」配合才能真正突破职业天花板）/
  无限耐久（全部、仅武器）/ 全员支援 A / 支援增长拉满 /
  支援距离 30 格、63 格，可整体撤销。
  「全员支援 A」「支援距离」均已实机验证通过。
  **无限耐久用的是游戏自带机制**：道具 `attributes` 的 bit3（`IA_UNBREAKABLE`），
  原版的最终之暗、火龙石就是这么实现的，游戏内耐久显示为 `--`。
  提供「全部道具」与「仅武器」两种口径。**已用「铠甲的呼唤」实机验证**：全道具均变为无限。
  **三倍经验**改的是职业表的经验分母（`classRelativePower`，三版本都在 `+0x1A`），
  原版多数职业为 3，改成 1 即约三倍。
  **成长率可写 200%**（字段上限已放宽到 255；注意属性仍会被职业「能力上限」封顶，
  想突破天花板需配合改上限或用属性强化预设）。
  **支援距离**（已实机验证）：原版支援加成要求两人相距不超过 3 格才生效（距离按
  「横纵坐标差之和」算，不是含对角线的九宫格）。可改成 30 格（常规 15×10
  地图全屏）或 63 格（覆盖 32×32 等任意战场）。定位靠指令特征扫描，
  改版 ROM 搬过代码也能找到；找不到时会在结果里明确提示「跳过」而不是乱写。
  **默认只改我方角色**——单位表里没有阵营字段（阵营在关卡事件里，
  同一角色可能前期是敌人、后期被说服加入），默认用「支援互惠」判据：
  角色至少有一个支援对象在对方列表里回指它（原版三作与旧口径命中数一致，
  改版上能排除半成品支援对话；FE8 实测 33/255 条，三个 ROM 一致）。
  页面顶部可切「按章节出场」（v2.3.09 新增，推荐用在改版上）/
  **「按出场，含事件动态」（v2.3.16）** /「有支援数据」（宽松版）/
  「按图鉴排序」（多 13 条，含敌方主要角色）/「全部单位」；
  **还有第五个选项「自定义名单」**（v2.3.12）：以当前判据的结果为初始勾选，
  进去发现漏了谁就补勾、多了敌方就取消；点「复制配置」把名单导出成
  `1,2,5,12,48` 这样的纯数字文本直接贴群/评论区，别人点「从剪贴板导入」
  就能复现同一份名单（自动从任意文本抽数字，越界与重复会过滤并提示）。
  名单按 ROM 指纹存本地，换 ROM 不会串。
  **改版请先试「按章节出场」**：改版经常不给主线主角配支援对话
  （实测 The Last Promise v1.5 主角辛格弗雷德支援指针为 0），
  支援类判据会漏掉他，成长率类预设就「看起来没用」；
  这个判据把章节初始单位里出场过的角色也算进来（自动排除对战/试炼塔章节）。
  **「含事件动态」再往前一步**（v2.3.16）：把事件脚本里以蓝方出场的角色也算进来，
  剧情增援、后期加入的我方都在这一层（实测烈火日版 52 → 60 条、圣魔 42 → 44 条）；
  红方敌军与绿方 NPC 不计，但会带入一次性剧情友兵，想精确请配合「自定义名单」。
  后两者（图鉴/全表）会带入疑似敌方，应用前确认弹窗会逐个点名那些
  「有图鉴排序但没有支援数据」的角色（章节静态表/事件里以蓝方出场过的不再算嫌疑），
  只改我方的话切回前几项即可。
- **日志**：错误与操作记录（ROM 打开 / 修改器应用 / 导出 / 未捕获异常）写在设备本地文件，
  工具区「日志」页可查看、一键复制全部、清空（上限 512KB 自动截断）
- **关于**：应用信息、更新日志、关于本工具、开源致谢与参考、免责声明；
  未开 ROM 时也能进（工具区入口）
- **表地址**：可手动指定各数据表的基址，用于表被搬到别处且指针槽失效的改版
- **导出**：改后 GBA、UPS 补丁（推荐）、IPS 补丁（16MB 内），走系统「另存为」

主页为网格分组（每行 3 列）：
- **游戏数据**：角色 / 职业 / 道具 / 章节
- **素材预览**：肖像 / 文本 / 战斗动画
- **工具**：修改器 / 十六进制 / 反汇编 / 空位搜索 / 表地址 / 设置 / 日志 / 关于

## 关于「耐久」「必杀」与道具特性

原版道具表**确实有耐久字段**（`+20`），就是游戏内显示的「46/46」的分母。
「威力」（`+21`）是武器自身的攻击力，游戏内看到的「攻击」= 角色力量 + 威力。
「必杀」在 `+24`，`+26` 是单价（**u16**，`耐久 × 单价 = 商店售价`）。
原版道具表**没有「回避」字段**（回避由速度/幸运算出）。

`+8` 起是 4 字节的 `attributes` 标志位，位含义取自 fireemblem8u 的 `enum { IA_* }`。
早期版本只读了 `+8` 这一个字节、把位含义按实测猜成「使用后消失 / 专用武器 / 不可丢弃」，
两处都不对：bit2 其实是 `IA_STAFF`（杖），bit5 是 `IA_BRAVE`（连击两次），
bit8 的 `IA_REVERTTRIANGLE` 更是完全读不到——所在字节根本不在 u8 范围内。
这些字段的含义现在用「真实 ROM + 反编译结构体」双重确认。

## 属性（Affinity）与支援

角色属性在 `+9`（`CharacterData::affinity`），**不是 `+0x28`**——
`0x28` 是上面说的 4 字节 `attributes`，按单字节读永远是 0。
支援关系在 `+0x2C` 指向的 `SupportData`，结构是 7 字节角色 ID + 7 字节初始值 +
7 字节每回合增长 + 计数（`include/bmreliance.h`），已在 FE8 上与
`SupportData_Eirika` 的定义逐字节核对。

## 与 FEBuilderGBA 的关系

本项目代码为 **Dart 独立重写**（FEBuilderGBA 是 .NET/WinForms 47.8 万行，无法在安卓运行）。
照搬的是**数据与格式知识**：地址表数值、结构体字段布局、算法（Huffman/LZ77/4bpp tile/UPS/IPS）、
道具与射程等枚举、以及 `assets/tbl/*.tbl` 的中文码表（`assets/patches/` 的 115 个补丁已于 v2.1.11 移除）。

本项目代码独立实现。FE6/FE7/FE8 地址表数据参考 [FEBuilderGBA](https://github.com/FEBuilderGBA/FEBuilderGBA)
（GPL-3.0，7743 著）；中文码表（`.tbl`）提取自其发行数据。

**游戏内调试器**为 [Vesly](https://github.com/Veslyquix/ASM) 的作品
「This is a message from Lord Nergal. I await you on the dread isle.」
（简称 TiaMfLNiAyotDI，GPL-3.0）。本工具只把它的补丁数据重新打包成可离线安装的
形式，未修改调试器本体行为；调试器版权归原作者所有。

仅用于修改自己合法拥有的 ROM。

## 关于「角色属性 + 职业属性 = 游戏内属性」

角色表里存的基础属性**不是最终值，而是相对职业的增减量**。游戏内看到的属性是两者相加：

| 属性 | 角色表 | 职业表 | 游戏内显示 |
|---|---|---|---|
| 力量 | 2 | 6 | 8 |
| 技巧 | -1 | 6 | 5 |
| 速度 | -2 | 7 | 5 |
| 幸运 | 9 | 0 | 9 |
| 防御 | 4 | 6 | 10 |
| 体格 | 0 | 8 | 8 |
| HP | 7 | 18 | 25 |

所以角色表里出现 **负数**是正常设计（被削弱的上限角色），不是数据损坏。
移动力只由职业决定，角色表不存。

想让角色突破职业自带的属性天花板，需要同时改职业表的「能力上限」那组字段，
否则升级时仍会被压回去。

## 关于肖像与角色的对应

单位表的 face 字段到肖像索引不是简单相等：**FE6 的 face = 肖像索引 + 1**
（肖像 0 留给山贼那张通用敌人脸），FE7/FE8 则一一对应。截图上看到「罗伊头像变成珐」
这类错位就是这个换算写反导致的。程序会自动判版本并用正确方向换算，无需手动设置。

## 已知限制

- **文本写入**：v2.3.18 起支持明文引擎，**v2.3.20 补齐 Huffman（SJIS / 中文码表）与控制码对话编辑**。
  等长原地覆盖 → 变短提前结束符 → 变长找最长 0xFF 空位重指指针；Huffman 用 ROM 自带树逆编码后重定位。
  含控制码的对话用〔XX〕占位符保留控制码。GBK 只认识码表里有的字，字库没有的字会显示为空白；
  日版 SJIS 同理只限该 ROM 字符表里有的字。
- **FE8 汉化版（火花天龙剑 & 狼组）显示正式译名**：码表就是 `assets/tbl/FE8.tbl`，
  工具能正常解出文本（实测匹配率 0.88）。但解出来的是「厉昂」「撒说」「条健」这类字——
  当年汉化组按读音抓同音字塞码表、没考虑字义。**这不是 bug，是游戏本来的显示效果**。
  工具现在按 `nameTextId` 换成正式译名，覆盖：
  - 角色名 86 条（`lib/core/fe8_formal_names.dart`）
  - 职业名 63 条 + 道具名 163 条（`lib/core/fe8_formal_item_class_names.dart`）

  原始同音字仍保留在 `unitName()` / `className()` / `itemName()`，
  文本查看器看到的是原文。
- **FE8 改版「圣邪的意志」（狼组&火花天龙剑，约 2004 年）**：完整可用。
  BE8J、三个表基址与 FE8J 完全相同（unit 0x8582BC / class 0x85B668 / item 0x85E068）、
  条目数一致（255/128/206）、支援数据同样 33/255 条；角色/职业/道具/支援均可编辑。
  中文文本与 FE8 汉化版同机制（同音字，挂 FE8.tbl 后能解），但码位与汉化版**不通用**
  （「部队」：汉化版 `84A8 86AD`，本改版 `84A0 869D`），所以暂未做它的译名表。
- **「铠甲的呼唤」等重度改版名字显示正常**（已实测确认）。
- 肖像目前只读，写入/导入未做
- 战斗动画目前只读（可播放与导出 PNG），导入/替换未做
- **章节单位**：我方（普通/困难，FE7/FE8）＋ 遭遇战 6 槽（FE8，原版 12 章有敌军数据，
  敌军阵营位=2）＋ 红/蓝两路（FE6，敌军即红方），均可读可改；只改字段，不支持增删单位。
  剧情中途生成的增援在「章节事件」面板里**只读展示**（三作均已支持），不能修改或新增
- 地形砖块编辑未做（地图读取与渲染已完成，LZ77 压缩器也已就绪，但写回还没接界面）
- 职业的「特性标志位」已做成开关（v2.3.06）：职业编辑页「特性（CA_* 标志位）」区，
  8 个常用位（上级职业/坐骑/飞龙/天马/君主/女性/BOSS/最大等级 10）可勾选，
  按位写 `attributes` u32@40（`bmunit.h` CA_* 枚举 + 真实 ROM 逐位核对）；
  FE6 职业条目 72 字节、+40 是熟练度区，不开放。
  未做：转职加成拉满 / 全职业可转职 / 商店全道具（需先确认机制）
