# 火纹改版工具（fe_editor）

安卓端 GBA《火焰之纹章》三部曲 ROM 改版工具。Flutter 实现，零第三方插件依赖。

支持 GBA 原版三作：封印之剑（FE6）/ 烈火之剑（FE7J·FE7U）/ 圣魔之光石（FE8J·FE8U），
也兼容常见改版（TLP、佣兵公司、铠甲的呼唤、HoloEmblem 等 20~32MB 扩展 ROM）。

## 功能

### 游戏数据编辑

- **角色**：查看与编辑等级 / 属性 / 体格 / 武器熟练度 / 成长率 / 属性（Affinity）/ 支援关系
- **职业**：基础值 / 能力上限 / 成长率 / 转职加成 / 移动力 / 特性标志位（CA_*）勾选
- **道具**：威力 / 命中 / 重量 / 必杀 / 射程 / 单价 / 耐久 / 武器等级；
  特性（IA_*）勾选（无限耐久、连击、逆转三角、无视防御等）；16×16 小图标预览
- **章节**：地图渲染（含陷阱叠加层、真实单位小人）；
  单位列表（坐标 / 等级 / 职业 / 道具可改）；
  遭遇战敌方（FE8 六槽）；红/蓝两路（FE6）；
  事件脚本解析（触发条件 + 剧情增援，三作均支持，只读）

### 素材预览

- **肖像**：96×80 正脸 / 半目 / 闭眼 / 嘴型帧 / 地图头像 32×32 / 职业卡 80×80
- **文本查看器**：五种引擎自动适配（Huffman+SJIS / 明文 GBK / 明文 UTF-8 / Huffman+中文码表 / 未识别）
- **战斗动画**：逐帧浏览与播放，四套配色切换，导出 PNG

### 文本编辑

- 明文 UTF-8 / 明文 GBK / Huffman（SJIS 与中文码表）均可写
- 等长原地覆盖 → 变短提前结束符 → 变长找空位重指指针
- 含控制码对话用〔XX〕占位符保留；改动可整体撤销
- 角色/职业/道具详情页可直接改名

### 修改器（批量预设）

12 个预设一键应用（可整体撤销）：
成长率拉满 / 成长率 200% / 属性强化 / 熟练度 S / 三倍经验 /
职业能力上限 50·生命 60 / 全部道具无限耐久 / 仅武器无限耐久 /
全员支援 A / 支援增长拉满 / 支援距离 30 格 / 支援距离 63 格

作用范围六种口径可选：支援互惠（默认）/ 有支援数据 / 按章节出场 /
按出场（含事件动态）/ 按图鉴排序 / 全部单位；
另有「自定义名单」手工勾选 + 剪贴板分享导入。
选宽口径时应用前会拦截疑似敌方角色。

### 工具

- **十六进制编辑器**：点选字节 + 数字键盘改值，搜索，改过字节有底色标记
- **反汇编查看器**：ARM/Thumb 双指令集，点分支跳目标，改机器码，函数追踪
- **空位搜索**：查找连续 FF/00 空白区
- **表地址**：手动指定各数据表基址（应对表被搬到别处的改版）
- **导出**：改后 GBA / UPS 补丁 / IPS 补丁（16MB 内）
- **日志**：错误与操作记录，可查看、复制、清空
- **暗色模式**：跟随系统 / 浅色 / 暗色

## 支持的 ROM

| 作品 | 版本 | 大小 |
|---|---|---|
| 封印之剑 | 日版 / 狼组汉化 | 8MB |
| 烈火之剑 | 日版 / 美版 / Superxyj 汉化 | 16~18MB |
| 圣魔之光石 | 日版 / 火花&狼组汉化 | 16MB |
| 圣邪的意志（FE8 改版） | 中文 | 16MB |
| 铠甲的呼唤（FE8 重度改版） | UTF-8 | 20.8MB |
| 佣兵公司 / 黑暗护符 / HoloEmblem / TLP v1.5 | 各种改版 | 23~32MB |

ROM 识别靠结构匹配（不依赖 game code），扩展 ROM 的指针超 16MB 也能正确解析。

## 构建

```bash
flutter build apk --release --target-platform android-arm64,android-armeabi-v7a
```

测试：`flutter test`（需要 `game-rom/` 目录下有真实 ROM 样本）。

## 已知限制

- 肖像与战斗动画目前只读（导出 PNG 可以，写入/替换未做）
- 章节事件脚本只读解析，不支持修改
- 地形砖块编辑未做（读取与渲染已完成）
- 游戏内调试器不可用（补丁缺陷未修复，入口已关闭）
- 汉化版显示的是游戏内原文（同音字），工具提供角色/职业/道具的正式译名映射
