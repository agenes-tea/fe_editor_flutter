# 火纹改版工具（fe_editor）

安卓端 GBA《火焰之纹章》三部曲 ROM 改版工具。Flutter 实现，零第三方插件依赖。

支持 GBA 原版三作：封印之剑（FE6）/ 烈火之剑（FE7J·FE7U）/ 圣魔之光石（FE8J·FE8U），
也兼容常见改版（TLP、佣兵公司、铠甲的呼唤、HoloEmblem 等 20~32MB 扩展 ROM）。

## 功能

### 游戏数据编辑

- **角色**：查看与编辑等级 / 属性 / 体格 / 武器熟练度 / 成长率 / 属性（Affinity）/ 支援关系；详情页可看角色介绍文本
- **职业**：基础值 / 能力上限 / 成长率 / 转职加成 / 移动力 / 特性标志位（CA_*）勾选；详情页可看职业介绍
- **道具**：威力 / 命中 / 重量 / 必杀 / 射程 / 单价 / 耐久 / 武器等级；
  特性（IA_*）勾选（无限耐久、连击、逆转三角、无视防御等）；16×16 小图标预览；
  介绍 / 使用介绍文本；**数值加成表（9×s8，可为负）**；**专用锁定**（IA_LOCK↔CA_LOCK，
  如封印之剑仅主角 King 系可用）
- **章节**：地图渲染（含陷阱叠加层、真实单位小人）；
  **地形砖块编辑**（选砖块在地图上涂抹，保存写回，可撤销）；
  单位列表（坐标 / 等级 / 职业 / 道具可改，**数值点一下就手输**，道具与职业还能按名字搜索选择）；
  遭遇战敌方（FE8 六槽）；红/蓝两路（FE6）；
  事件脚本解析（触发条件 + 剧情增援，三作均支持，只读）；
  **添加剧情增援**（第 N 回合在指定格子生成指定单位，三作方言都能生成；只追加不改动既有脚本）；
  **宝箱奖励 / 商店换品**（事件表里宝箱行可直接换奖励道具，商店行可把某格换成另一件；
  原地写字节、可撤销；价格改不了——价格是道具表字段，去道具页改）；
  **本章对话**（列出事件脚本引用的对话文本，点条目直接编辑，可撤销）；
  **按场景编辑剧情**（把本章对话整理成「一场戏 → 一句一句」，
  顺着剧情读、逐句改，不用面对一堆文本编号）；
  **章节预览**（地图工具栏 👁）：对话时间线与事件触发两个视图，改完立刻刷新。
  注意：预览渲染的是工具解析出的数据，**不是游戏实际画面**——
  它只能验证数据自洽（文本 ID / 坐标 / 头像索引在不在范围内），
  不能验证「这段对话真会在第 3 回合触发吗」，后者得用模拟器 / 实机；
  **事件编辑**（地图工具栏 ⚡）：给本章追加一条新事件（第 N 回合 / 角色 / 地点），
  在指定坐标生成指定单位；可选填一个「台词文本 ID」，让新事件在生成单位前先显示一句既有台词（先把那段文本改好再填 ID）。
  **只追加不改既有脚本**（往既有脚本中间插指令做不了，见下），可删可撤销

### 素材预览

- **肖像**：96×80 正脸 / 半目 / 闭眼 / 嘴型帧 / 地图头像 32×32 / 职业卡 80×80
- **肖像移植**：把一张脸从已打开的一个 ROM 搬到另一个（跨版本自动转格式、颜色不走样）；
  可追加新条目，也可**直接替换**目标里已有的某一条（推荐，风险最低）
- **动画移植**：把一条战斗动画整包搬到另一个 ROM（脚本 / OAM / 调色板 / 全部图形），默认替换
- **文本查看器**：五种引擎自动适配（Huffman+SJIS / 明文 GBK / 明文 UTF-8 / Huffman+中文码表 / 未识别）
- **战斗动画**：逐帧浏览与播放，四套配色切换，导出 PNG

### 文本编辑

- 明文 UTF-8 / 明文 GBK / Huffman（SJIS 与中文码表）均可写
- 等长原地覆盖 → 变短提前结束符 → 变长找空位重指指针
- 含控制码对话用〔XX〕占位符保留；改动可整体撤销
- 角色/职业/道具详情页可直接改名
- **全 ROM 查找/替换**：文本页一键查找命中全部条目，预览确认后整批写回（变长自动重定位，可整体撤销）

### 修改器（批量预设）

13 个预设一键应用（可整体撤销；含「单角色全套强化」组合预设）：
成长率拉满 / 成长率 200% / 属性强化 / 熟练度 S / 三倍经验 /
职业能力上限 50·生命 60 / 全部道具无限耐久 / 仅武器无限耐久 /
全员支援 A / 支援增长拉满 / 支援距离 30 格 / 支援距离 63 格 / 单角色全套强化（组合：成长+熟练度+职业上限+三倍经验）

作用范围六种口径可选：支援互惠（默认）/ 有支援数据 / 按章节出场 /
按出场（含事件动态）/ 按图鉴排序 / 全部单位；
另有「自定义名单」手工勾选 + 剪贴板分享导入。
选宽口径时应用前会拦截疑似敌方角色。

### 工具

- **模拟器**：成长曲线（期望/最坏/最好 + 职业上限标记）与战斗推演
  （伤害/命中/必杀/追击/反击/一回合谁先死），角色/武器可搜索选择，
  **全部武器排名**（攻方逐个试完所有有威力的武器，按每回合期望伤害降序，点某行即选中该武器），
  支持「改前 vs 改后」同屏对比（改前 = 打开 ROM 时的原始快照）；
  战斗推演已把武器自带数值加成（+12 表）加到攻方属性上
- **多 ROM**：可同时打开多个 ROM（跨版本对照与素材移植的地基），顶部会话栏切换
- **外部工作区**：在主页「设置工作区」选一个存放 ROM 的目录（系统持久授权，重启仍有效）；
  之后每次进来直接从目录里列 ROM 点开，不用再走文件选择器。
  目录里只列 `.gba/.agb/.bin`。AI 也能通过 MCP 直接看到这个目录里的 ROM 并自己打开
- **缺字检查**：写剧情之前就知道哪些字在当前 ROM 上会显示成空白——
  文本编辑框敲字时实时提示，MCP 工具 `check_text_coverage` 也能逐字报出
- **开源仓库**：关于页可直接跳转 GitHub 查看源码（GPL-3.0）
- **十六进制编辑器**：点选字节 + 数字键盘改值，搜索，改过字节有底色标记
- **反汇编查看器**：ARM/Thumb 双指令集，点分支跳目标，改机器码，函数追踪
- **空位搜索**：查找连续 FF/00 空白区
- **表地址**：手动指定各数据表基址（应对表被搬到别处的改版）
- **导出**：改后 GBA / UPS 补丁 / IPS 补丁（16MB 内）
- **导入配方**：选一份别人（或 AI）导出的配方 JSON，预览确认 → 自动快照 → 应用 → 自动体检，
  不满意可一键回退本次导入
- **MCP 服务器**：设置页开启后监听 `http://127.0.0.1:8422`，AI 客户端可经 MCP 协议
  直接查表、改字段、搬素材（59 个工具 + 4 个资源 + 10 个任务模板，与界面共用同一份 ROM 缓冲区）
- **ROM 体检**：检查表基址与边界、单位/职业/道具的 ID 连续性、角色默认职业越界、
  道具指针、支援引用、章节单位坐标是否在本章地图内；致命问题与警告分列，随时可重新体检
- **日志**：错误与操作记录，可查看、复制、清空
- **暗色模式**：跟随系统 / 浅色 / 暗色

## 做剧情改版该用哪份 ROM 当底子

这个工具最实在的用途是「拿原版当蓝本，一章一章换成自己的剧情和人物」。
动手前先选对基底 ROM，能省掉大量返工——差别就在**字库**：

| 基底 | 文本引擎 | 字库情况 | 适合 |
|---|---|---|---|
| **烈火之剑 Superxyj 汉化** | 明文 GBK | 常用汉字几乎不缺（GB2312 全覆盖） | **剧情改版首选** |
| 烈火/圣魔 日版 | Huffman + SJIS | 日文字库，简体人名和常用汉字大量缺 | 不建议做中文剧情 |
| 圣魔 火花&狼组汉化 | Huffman + 中文码表 | 约 2500 字，是按当年剧情挑的子集 | 只改原有台词可以 |
| 重度改版（UTF-8 扩展 ROM） | 明文 UTF-8 | 几乎不限字 | 但关卡/演出已被别人改过 |

先写好一段典型台词（人名 + 地名 + 兵器名 + 常见动词），用「缺字检查」比一比再决定。
缺字不会报错，只会让游戏里少几个字，事后很难发现。

## 支持的 ROM

| 作品 | 版本 | 大小 |
|---|---|---|
| 封印之剑 | 日版 / 狼组汉化 | 8MB |
| 烈火之剑 | 日版 / 美版 / Superxyj 汉化 | 16~18MB |
| 圣魔之光石 | 日版 / 火花&狼组汉化 | 16MB |
| 圣邪的意志（FE8 改版） | 中文 | 16MB |
| 铠甲的呼唤（FE8 重度改版） | UTF-8 | 20.8MB |
| 佣兵公司 / 黑暗护符 / HoloEmblem / TLP v1.5 | 各种改版 | 23~32MB |

ROM 识别靠结构匹配（不依赖 game code），扩展 ROM 的指针超 16MB 也能正确解析。

## 构建

```bash
flutter build apk --release --target-platform android-arm64,android-armeabi-v7a
```

测试：`flutter test`（需要 `game-rom/` 目录下有真实 ROM 样本）。

## 为 AI 协作准备的机制

MCP 不是「直接写字节」就完了，围绕「AI 改错一步就得靠人肉发现」补了一层安全网：

- **`describe_rom`**：一次拿到版本、文本引擎、表规模与可用 ID 范围、可编辑字段名、
  章节标题、我方判据、已知限制——AI 不用猜偏移
- **`dry_run: true`**：任何写 ROM 的工具都支持（实际执行后立即回滚），返回将改的字节区间
- **`snapshot` / `rollback`**：显式事务，可回到任意一次快照点，不止「撤销全部」
- **`validate_rom`**：改完静态体检，与界面「ROM 体检」共用同一套检查代码
- **`export_recipe`**：把改动导出成可重放的「修改配方」，便于分享与复现
- **`apply_recipe` + 语义层配方**：配方可带一层「意图」（预设 ID + 角色/道具名 + 字段名），
  导入时按名字重新解析——同版本的另一份 ROM 也能用；字节层则精确重放
  （指纹不一致自动跳过并提示，不误写）。界面导出面板的「导入配方」走同一套引擎
- **resources / prompts**：客户端可直接展示 ROM 概览、字段清单、章节清单与常见任务模板
  （含 3 个新手向导：加强某角色全套 / 给某章加增援 / 改写某章对话）

## 已知限制

- 战斗动画可整包移植（替换或追加），但**不支持逐帧 / 指令级编辑**，音效不随动画搬运
- 肖像移植不会自动挂到角色身上（要改角色的 portrait 字段才算真正换脸）
- 职业数量上限：三作的职业表都能重定位扩容，但原版存档存不下超出范围的新职业 ID。
  圣魔可用社区的 ExModularSave 补丁解决，封印与烈火没有对应补丁。
  因此改版建议**替换已有职业**而不是新增——本工具的所有移植功能都按这个思路设计
- 章节单位只能改字段，不能增删（原版三作单位表都是满表；`clone_unit` 只填空槽）；
  事件脚本仍不支持任意指令编辑，目前只有「回合增援」这一个模板；
  但**宝箱奖励与商店卖品可改**（原地写字节，可撤销）
- 战斗模拟是**近似值**：不计地形、支援、三角武器与特効；反击按徒手速度；
  武器自带数值加成表（+12，9×s8）已计入攻方属性
- 章节事件脚本只读解析，不支持修改；但**章节对话可编辑**（对话文本按 ID 引用，
  改的是文本条目本身，不动事件脚本）
- 地形编辑只支持砖块（地图块），不支持改地图宽高，也不支持编辑砖块本身的 TSA 图形；
  地图数据由多个章节共享，改动过大（压缩后放不下）时会被拒绝而不是搬家
- 游戏内调试器不可用（补丁缺陷未修复，入口已关闭）
- 汉化版显示的是游戏内原文（同音字），工具提供角色/职业/道具的正式译名映射

### 关于网络权限

本工具申请 `INTERNET` 权限**仅**用于 MCP 调试功能（设置页开启后才生效）：
MCP 服务器默认只监听 `127.0.0.1`，不向外网发起任何连接，
也不会上传你的 ROM、游戏数据或个人信息。MCP 默认关闭。

仅用于修改自己合法拥有的 ROM。
