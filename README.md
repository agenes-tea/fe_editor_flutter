# 火纹改版工具（fe_editor）

安卓端的 GBA《火焰之纹章》三部曲 ROM 改版工具。Flutter 实现，**零第三方插件依赖**，
对标 Windows 上的 FEBuilderGBA。

[English](README.en.md) | 简体中文

支持 GBA 原版三作：封印之剑（FE6）/ 烈火之剑（FE7J·FE7U）/ 圣魔之光石（FE8J·FE8U），
也能打开常见社区改版（TLP、佣兵公司、铠甲的呼唤、HoloEmblem 等 20~32MB 扩展 ROM）。

## 能做什么

### 角色 / 职业 / 道具

- **角色**：等级、属性、体格、武器熟练度、成长率、属性（Affinity）、支援关系；
  肖像与介绍文本；按名字搜索跳转。
- **职业**：基础值、能力上限、成长率、转职加成、移动力、体格、特性标志位（CA_*）；
  介绍文本；**地形表**（移动消耗与地形回避/防御/魔防，按地形逐项改）。
- **道具**：威力、命中、重量、必杀、射程、单价、耐久、武器等级；
  特性位（IA_*）勾选；16×16 小图标；介绍与使用介绍；
  **数值加成表（9 项，可为负）**；**专用锁定**（如封印之剑只让特定角色用）。

### 章节

- 地图渲染（含陷阱层与真实单位小人）；点格子可看砖块值与当前站位单位。
- **地形砖块编辑**：选砖块在地图上涂抹，保存写回，可撤销。
- **砖块图形编辑**：改 TSA 图形本身（地形长什么样），以及**地图宽高**（会点名受影响的共享章节）。
- **初始单位**：坐标、等级、职业、道具都能改——数值点一下可手输，职业与道具有可搜索清单。
  含遭遇战敌方配置（仅圣魔）与红/蓝两路（仅封印）。

### 剧情与事件

- **事件解析**：本章有哪些触发条件（回合 / 角色 / 地点 / 其它），各自生成了哪些单位。
- **追加事件**：在列表末尾加一条触发，在指定坐标生成指定单位；
  可选让它在生成前先显示一句既有台词。**只追加，不改动游戏原有的脚本**。
- **改事件单位**：剧情增援的等级、职业、坐标、道具、阵营。
- **宝箱奖励与商店卖品**：在事件表里直接改（原地写字节，可撤销）。
- **章节对话**：列出本章引用的文本逐条改；也可「按场景编辑」——
  把对话整理成「一场戏 → 一句一句」，顺着剧情读和改。支持整章导入导出。
- **章节预览**：对话时间线与事件触发两个视图，改完立刻刷新。
  注意：预览渲染的是工具解析出的数据，**不是游戏实际画面**；
  它只能验证数据自洽（文本 ID / 坐标 / 索引在不在范围内），
  「这段对话真会在第 3 回合触发吗」仍要用模拟器或实机确认。

### 素材

- **肖像**：96×80 正脸、半目、闭眼、嘴型帧、32×32 地图头像、80×80 职业卡。
- **肖像移植**：把一张脸从一个 ROM 搬到另一个（跨版本自动转格式，颜色不走样），
  可追加新条目，也可直接替换目标里已有的某一条。
- **肖像编辑器**：把外部图片（PNG / JPG）转成游戏肖像——自动缩放、量化到 16 色、
  背景抠成透明。支持 FEBuilderGBA 导出的 128×112 完整素材图（带嘴型与眨眼真帧）；
  嘴型与眨眼各三档（真实帧 / 固定 / 无）；可选同时换 32×32 地图小头像。
- **战斗动画**：逐帧浏览、四套配色、导出 PNG；可整包移植到另一个 ROM。
- **文本查看器**：五种引擎自动适配（Huffman + SJIS、明文 GBK、明文 UTF-8、
  Huffman + 中文码表、未识别），支持全 ROM 查找替换。
- **缺字检查**：写剧情之前就知道哪些字在当前 ROM 上会显示成空白；编辑框里敲字时实时提示。
- **素材库**：指定一个设备目录存放导出的素材，库里的 PNG 可一步写成游戏肖像。

### 工具

- **修改器**：13 个批量预设（成长率拉满 / 200%、属性强化、熟练度 S、三倍经验、
  职业能力上限、无限耐久、全员支援 A、支援增长与距离、单角色全套强化），
  作用范围六种口径可选（另有自定义名单）。选宽口径时应用前会拦下疑似敌方角色。
- **模拟**：成长曲线（期望 / 最坏 / 最好，标注职业上限）、战斗推演、
  全武器排名、改前 vs 改后同屏对比。
- **十六进制编辑器**：点选字节 + 数字键盘改值，搜索，改动标色。
- **反汇编查看器**：ARM / Thumb，点分支跳转，改机器码。
- **补丁**：社区补丁库（FEBuilderGBA 补丁，仅「固定字节写入」类）；
  应用外部 UPS / IPS 补丁；导出改后 GBA 或 UPS / IPS 补丁。
- 多 ROM 同时打开、外部工作区、手动指定表地址、空位搜索、ROM 体检、
  导入修改配方、分享 ROM 给模拟器、日志、暗色模式。

## 做剧情改版该用哪份 ROM 当底子

差别就在**字库**。缺字不会报错，只会让游戏里少几个字，事后很难发现：

| 基底 | 文本引擎 | 字库情况 | 适合 |
|---|---|---|---|
| **烈火之剑 Superxyj 汉化** | 明文 GBK | 常用汉字几乎不缺（GB2312 全覆盖） | **剧情改版首选** |
| 烈火 / 圣魔 日版 | Huffman + SJIS | 日文字库，简体人名和常用汉字大量缺 | 不建议做中文剧情 |
| 圣魔 火花&狼组汉化 | Huffman + 中文码表 | 约 2500 字，按当年剧情挑的子集 | 只改原有台词可以 |
| 重度改版（UTF-8 扩展 ROM） | 明文 UTF-8 | 几乎不限字 | 但关卡与演出已被别人改过 |

先写好一段典型台词（人名 + 地名 + 兵器名 + 常见动词），用「缺字检查」比一比再决定。

## 支持的 ROM

| 作品 | 版本 | 大小 |
|---|---|---|
| 封印之剑 | 日版 / 狼组汉化 | 8MB |
| 烈火之剑 | 日版 / 美版 / Superxyj 汉化 | 16~18MB |
| 圣魔之光石 | 日版 / 火花&狼组汉化 | 16MB |
| 社区改版 | 圣邪的意志 / 铠甲的呼唤 / 佣兵公司 / 黑暗护符 / HoloEmblem / TLP v1.5 | 16~32MB |

ROM 识别靠结构匹配（不依赖 game code），扩展 ROM 的指针超过 16MB 也能正确解析。

## 构建

```bash
flutter build apk --release --target-platform android-arm64
```

测试：`flutter test`（需要 13 个真实 ROM 样本）。
ROM 有版权、不进仓库，测试通过 `FE_ROM_DIR` 指定样本目录：

```bash
flutter test --dart-define=FE_ROM_DIR=/path/to/game-rom
```

不指定时默认读工程旁边的 `../game-rom/`。`FE_ROM_DIR` 也可用于 `tool/debugger_patch/fe8_build.py`。

## 为 AI 协作准备的机制

内嵌 MCP 服务器（设置页开启，默认只监听 `127.0.0.1:8422`），AI 客户端可以经 MCP 协议
直接查表、改字段、搬素材，与界面共用同一份 ROM 缓冲区。围绕「AI 改错一步就得靠人肉发现」
补了一层安全网：

- **`describe_rom`**：一次拿到版本、文本引擎、表规模与可用 ID 范围、可编辑字段名、
  章节标题、我方判据与已知限制——AI 不用猜偏移。
- **`dry_run`**：任何写 ROM 的工具都支持（真跑一遍后立即回滚），返回将改的字节区间。
- **`snapshot` / `rollback`**：显式事务，可回到任意一次快照点，不止「撤销全部」。
- **`validate_rom`**：改完静态体检，与界面「ROM 体检」共用同一套检查。
- **`export_recipe` / `apply_recipe`**：把改动导出成可重放的配方（可带「意图层」按名字解析），
  便于分享与复现。
- **资源与任务模板**：ROM 概览、字段清单、章节清单，以及若干新手向导
  （加强某角色 / 给某章加增援 / 改写某章对话 / 从零开始做剧情改版）。

## 已知限制

- **不支持往游戏原有的事件脚本里插指令**。工具只能「追加一条新事件」，
  既有脚本一个字节都不动——这是刻意划的安全边界（插指令要重算后续跳转，实测不可靠）。
- **不支持给 ROM 扩容或新建章节**：原版三作的表、文本区、事件区都是满的；
  扩展 ROM 靠改版者自己打寻址补丁，本工具只支持读。
- 章节单位只能改字段，不能增删条目；商店只能原地换品（不能增删商品，价格去道具表改）。
- 肖像编辑器只换**正脸与调色板**（可选 32×32 小头像）。
  从一张静态图推不出五官位置，所以普通图片不生成嘴型与眨眼帧；
  需要真帧请导入 FEBuilderGBA 导出的 128×112 完整素材图。
- 战斗动画不支持逐帧 / 指令级编辑，音效不随动画搬运。
- 战斗模拟是**近似值**：不计地形、支援、三角武器与特効。
- 地形编辑只能就地覆盖（地图数据跨章节共享，压缩后放不下会被拒绝而不是搬家）。
- 职业数量受存档限制：圣魔可用社区 ExModularSave 补丁绕过，封印与烈火没有对应补丁，
  所以改版建议**替换已有职业**而不是新增。
- 游戏内调试器尚未开放（补丁缺陷未修复，入口关闭）。
- 汉化版显示的是游戏内原文（圣魔汉化版有同音替代字），
  工具对角色 / 职业 / 道具提供了正式译名映射。

### 关于网络权限

本工具申请 `INTERNET` 权限**仅**用于 MCP 调试功能（设置页开启后才生效）：
MCP 服务器默认只监听 `127.0.0.1`，不向外网发起任何连接，
也不会上传你的 ROM、游戏数据或个人信息。MCP 默认关闭。

仅用于修改自己合法拥有的 ROM。
