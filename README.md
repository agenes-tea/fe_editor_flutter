# 火纹改版工具（fe_editor）

安卓端 GBA《火焰之纹章》三部曲 ROM 改版工具。Flutter 实现，零第三方插件依赖。

**接手开发前请先读 `~/workspace/AGENTS.md`**——里面有构建命令、字段布局、已知的坑和待办。

## 功能

- **ROM 识别**：不依赖 game code，改用「结构匹配」——看哪个版本的指针槽在 ROM 里全部有效。能兼容改版改写 game code 的情况（如 BE8E 的 20MB 重度改版「铠甲的呼唤」）
- **角色 / 职业表**：浏览与数值编辑（等级、属性、成长率、移动、体格），改动可撤销，导出前不写文件。列表 ID 恒等于表内偏移，空条目显示为「（未命名）」而不跳过
- **道具浏览**：按种类分组（剑 / 枪 / 斧 / 弓 / 杖 / 理光闇魔法 / 消耗品 / 指环 / 龙石），可搜索、可按种类筛选。详情页显示：
  - 种类、可装备、使用后消失、专用武器、不可丢弃
  - **使用次数 / 耐久**（游戏里「46/46」的分母）
  - 重量、命中、威力、助、回避、射程
  - 武器等级（E~S）与熟练度累计值（FE7/FE8）
  - 数值加成（HP/攻击/技巧/速度/防御/魔防/幸运/移动/体力）
  - 可使用职业列表
- **肖像浏览**：枚举全部角色肖像，按 sheet 拼装 96×80 正脸，另可看半目/闭眼、嘴型帧、32×32 地图头像与 80×80 职业卡（只读，自动适配 FE6/FE7/FE8 三种数据布局与 LZ77）
- **文本查看器**：枚举全部对话文本，控制码渲染为可读符号，支持搜索；自动适配三种文本引擎（标准 Huffman+SJIS / 明文 GBK 汉化 / Huffman+中文码表汉化）
- **十六进制编辑器**：按地址查看与修改任意字节、按十六进制搜索
- **空位搜索**：查找连续 FF/00 空白区
- **补丁库**：内置 116 个 FEBuilderGBA 社区补丁，一键安装 / 撤销 / 搜索
- **表地址**：可手动指定各数据表的基址，用于表被搬到别处且指针槽失效的改版
- **导出**：改后 GBA、UPS 补丁（推荐）、IPS 补丁（16MB 内），走系统「另存为」

主页为网格分组（每行 3 列）：**游戏数据** / **素材预览** / **工具**。

## 关于「耐久」

原版道具表**确实有耐久字段**（`+20`），就是游戏内显示的「46/46」的分母。
「威力」（`+23`）是武器自身的攻击力，游戏内看到的「攻击」= 角色力量 + 威力。
这些字段的含义是用真实 ROM + 游戏内截图逐项比对确认的。

## 构建

```bash
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-arm64
export PATH="$PATH:/root/.local/flutter-3.27.4/bin"
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn

cd ~/workspace/fe_editor
flutter build apk --release --target-platform android-arm64
```

测试：`flutter test`（107 个用例，需要 `~/workspace/game-rom/` 下有真实 ROM 样本）。

## 与 FEBuilderGBA 的关系

本项目代码为 **Dart 独立重写**（FEBuilderGBA 是 .NET/WinForms 47.8 万行，无法在安卓运行）。
照搬的是**数据与格式知识**：地址表数值、结构体字段布局、算法（Huffman/LZ77/4bpp tile/UPS/IPS）、
道具与射程等枚举、以及 `assets/patches/` 的补丁和 `assets/tbl/*.tbl` 的中文码表。

本项目代码独立实现。FE6/FE7/FE8 地址表数据参考 [FEBuilderGBA](https://github.com/FEBuilderGBA/FEBuilderGBA)
（GPL-3.0，7743 著）；内置补丁与中文码表（`.tbl`）提取自其发行数据，补丁版权归各补丁原作者
（见补丁详情页 AUTHOR 字段）。仅用于修改自己合法拥有的 ROM。

## 已知限制

- 文本写入未做
- FE8 汉化版中文乱码（同码位不同字，码表未破解）
- 重度改版（如「铠甲的呼唤」）的文本引擎未破解，角色名显示为空
- 肖像目前只读，写入/导入未做
- 战斗动画预览未做
- ADDR 类补丁（需交互式参数输入）未支持
